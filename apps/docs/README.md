# Documentation

Source for the FlareDispatch documentation. Two kinds of file live here and they are maintained
differently:

- **Guides** — hand-written, reviewed like code. [`substrate/`](substrate/README.md). They are
  not published on the site.
- **Reference** — generated by TypeDoc from the package it documents, and committed.
  [`reference/`](reference/substrate-contract/README.md). Never edit a file under `reference/`;
  run `pnpm docs:reference` and commit what it writes.

`.github/workflows/docs.yml` regenerates the reference on every pull request and fails when the
committed output differs from what the current source produces. A hand-maintained API reference
drifts from the types consumers actually pin, and the drift stays invisible until someone follows it
into a compile error.

The site at <https://flare-dispatch.fractalbox.dev> is an Astro build of this directory. The product
page (`/`) and `/benchmarks/` are plain Astro pages in [`src/pages/`](src/pages/) with their own
layout and stylesheet; the specifications under `/docs/` are Starlight. `/benchmarks/` prices the
workload profiles in [`src/data/benchmarks.ts`](src/data/benchmarks.ts) through the cost engine
(`packages/core/src/cost.ts`) at build time. `public/_redirects` maps older
paths to their `/docs/` pages.

[`src/content/docs/docs`](src/content/docs/docs) is a relative symbolic link to
[`specs/`](../../specs/README.md), so each specification and decision record has one copy
and reads the same on GitHub and on the site: `specs/README.md` is `/docs/`, `specs/spend.md` is
`/docs/spend/`, `specs/adr/` is `/docs/adr/`. [`src/lib/pages.mjs`](src/lib/pages.mjs) derives
each page's title and description from its first heading and paragraph, and rewrites relative
links to site URLs (or to GitHub, for files that are not pages).
[`src/lib/nav.mjs`](src/lib/nav.mjs) holds the sidebar sections, which `/llms.txt` and
`/llms-full.txt` follow.

Every ```` ```mermaid ```` block renders to inline SVG at build time through Merlion
([`vendor/merlion/`](vendor/merlion/README.md)), which supports flowchart, sequence and state
diagrams. `node apps/docs/scripts/check-diagrams.mjs specs/**/*.md` renders every diagram
without a full build and fails on an unsupported type or a parse error.

To publish another spec, add the file to `specs/` and its path to a section in `nav.mjs`. The
build fails on a broken internal link.

```sh
pnpm --filter @fractalboxdev/flare-dispatch-docs run dev     # local preview
pnpm --filter @fractalboxdev/flare-dispatch-docs run build   # what CI runs
```

`.github/workflows/docs.yml` builds the site on every pull request and deploys it on `main`, to a
static-assets Worker (`wrangler.jsonc`). The dispatcher Worker — API, webhooks, dashboard, log
viewer — serves the custom domain the root `wrangler.jsonc` routes.
