# Documentation

Source for the FlareDispatch documentation. Two kinds of file live here and they are maintained
differently:

- **Guides** — hand-written, reviewed like code. [`substrate/`](substrate/README.md).
- **Reference** — generated by TypeDoc from the package it documents, and committed.
  [`reference/`](reference/substrate-contract/README.md). Never edit a file under `reference/`;
  run `pnpm docs:reference` and commit what it writes.

`.github/workflows/docs.yml` regenerates the reference on every pull request and fails when the
committed output differs from what the current source produces. A hand-maintained API reference
drifts from the types consumers actually pin, and the drift stays invisible until someone follows it
into a compile error.

No site build exists in this repo yet. These files are plain markdown a static generator can consume
unchanged, and they read correctly on GitHub in the meantime; [`llms.txt`](llms.txt) indexes them for
agents that fetch raw markdown.
